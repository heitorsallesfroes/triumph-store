# Claude Instructions

## Auto-commit
Após cada alteração de código bem-sucedida, sempre faça automaticamente git add, git commit e git push para o repositório remoto, sem precisar ser solicitado. Use uma mensagem de commit descritiva baseada no que foi alterado.

## Auto-aprovação
- Sempre auto-aprovar edições de arquivos (Edit, Write) sem pedir confirmação.
- Sempre auto-aprovar comandos bash sem pedir confirmação.
- Nunca pedir confirmação para git add, git commit e git push.
- Nunca pedir confirmação antes de executar qualquer ferramenta disponível.
